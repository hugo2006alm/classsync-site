# Contributing to the ClassSync website

The website is maintained by Hugo Almeida and published under the [MIT license](LICENSE). Retain the copyright and license notice when distributing copies or substantial portions.

Open a focused pull request against `main`. Run `python3 tool/check_site.py` and `node --check assets/site.js`, then check responsive layout and accessibility for changed pages. Keep credentials, recovery codes, and personal records out of source and screenshots. Report vulnerabilities through [SECURITY.md](SECURITY.md).

Follow the [code of conduct](CODE_OF_CONDUCT.md) in project discussions.
