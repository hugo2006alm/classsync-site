Start with the path that matches your setup.

If you are installing ClassSync for the first time, use the guided setup. If you are running your own infrastructure, the self-host guide covers Cloudflare Worker + D1 and the bootstrap secret.

First-run setup

Get the Fireflies, Gemini and Notion credentials, connect the relay, then configure your private webhook.

Self-host the relay

Deploy the Worker and D1 database, set the required secrets and point the app at your own URL.

What ClassSync connects

F

Fireflies

Source of completed meeting transcripts and webhook notifications.

G

Gemini

Optionally identifies the class with a lightweight model and produces the structured study summary. Settings use named model dropdowns.

N

Notion

Provides the subject catalogue and stores the final notes.

R

ClassSync relay

Coordinates devices and webhook delivery without receiving transcript or summary content.

Already configured? Use Use recovery code on the welcome screen before entering API keys. A complete synced account can restore the shared ClassSync configuration to a new device.
Review stays under your control. Every job lets you choose or correct its active Notion class. Mobile job details can open the complete locally retained transcript in a full-screen reader. Other devices receive bounded status and Notion-link metadata, not transcript or summary content.
