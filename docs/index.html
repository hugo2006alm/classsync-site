Documentation

Start with the path that matches your setup.

For a normal hosted installation, ClassSync only needs your Fireflies API key, Gemini API key and Notion integration token. The hosted relay is open for account creation and the app discovers its registration mode automatically. Self-hosted relays can instead use open, invite or token registration.

First-run setup

Install ClassSync, connect Fireflies, Gemini and Notion, create your private account, then configure your personal Fireflies webhook.

Self-host the relay

Clone the public repository, deploy the Worker and D1 database, choose a registration policy and point the app at your own relay.

What ClassSync connects

F

Fireflies

Source of completed meeting transcripts and webhook notifications.

G

Gemini

Optionally identifies the class and produces the structured study summary with user-selectable named models.

N

Notion

Provides the subject catalogue and stores the final notes.

R

ClassSync relay

Coordinates private accounts, devices and webhook delivery without receiving transcript or summary content.

I

ISEP Portal

Optional read-only academic data such as timetable, exams, grades, absences, calendar, notices and finance.

M

Moodle

Optional enrolled courses, assignments and announcements with reviewable subject mappings.

Already configured? Use Use recovery code on the welcome screen. Recovery restores the encrypted shared configuration for that account and does not require an invite or registration token.
Outside ISEP? Leave ISEP Portal and Moodle off during setup. The lecture summary pipeline, local tasks, and manual evaluations still work. You can enable those sources later under Settings → Connections.
Updating an existing install? Install the newer build over the current one instead of uninstalling. The current source also includes GitHub-release update checks; use Settings → App updates & widget on releases that include that feature.
Review stays under your control. Every lecture job lets you choose or correct its active Notion class. Other devices receive bounded status and Notion-link metadata, not transcript or generated-summary content.
